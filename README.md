# QR TEST

אב־טיפוס עצמאי למבחן אוצר מילים הנפתח באמצעות QR חד־פעמי.

## מה עובד בשלב 1

- המורה עובד עם חפיסת כרטיסים שניתנת להחלקה ולגרירה במגע או בעכבר.
- משיכה ימינה או שמאלה מחליפה את הכרטיס ומפיקה קישור ו־QR חד־פעמיים חדשים.
- אין אפשרות לחזור לכרטיס קודם; הקוד שכבר נמסר לתלמיד נשאר תקף.
- הפיילוט מוגבל לעשרה כרטיסים.
- פתיחת הקישור או תצוגה מקדימה אינן צורכות את הקוד.
- הקוד נתפס רק בלחיצה על **התחלת המבחן**.
- מכשיר אחד בלבד יכול להתחיל; אותו מכשיר יכול לרענן ולהמשיך.
- מבחן דמה כולל 10 שאלות אוצר מילים.
- הציון נקבע לפי התשובה הראשונה ונשמר בדפדפן התלמיד בלבד.
- בסיום הקוד נסגר לשימוש נוסף.
- אפשר להדפיס או לשמור את מסך התוצאה כ־PDF.

## הרצה מקומית

נדרשים Node.js 20 ומעלה.

```bash
npm install
npm start
```

לאחר מכן פותחים בדפדפן:

```text
http://127.0.0.1:3000
```

כדי לדמות שני מכשירים, פותחים את קישור התלמיד בשני דפדפנים שונים או בדפדפן רגיל ובחלון פרטי.

## בדיקות

```bash
npm test
```

הבדיקות מכסות תצוגה מקדימה ללא צריכה, תפיסה של מכשיר יחיד, חידוש מאותו מכשיר, חסימת שימוש חוזר וניקוד לפי התשובה הראשונה.

## גבול הנתונים

השרת שומר רק hash של הקוד, מזהה וגרסת המבחן, מצב הקוד, זמנים ו־hash של מזהה המכשיר. שם תלמיד, תשובות וציון אינם נשלחים לשרת.

הציון מחושב בצד התלמיד ולכן אינו חסין משינוי בידי משתמש טכני. הדבר מכוון ומקובל בשלב האב־טיפוס.
